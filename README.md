# reels-pipeline

Сборка для монтажа вертикальных рилсов из «говорящей головы» с помощью **Claude Code + Remotion**: расшифровка речи, обрезка до сути, кадр 9:16, субтитры по смыслу, мемная и историческая графика, дозированные звуки, рендер и самопроверка готового ролика.

Выросла из реального ролика про то, как «Франкенштейн» написали на спор (1:34, ~20 графических вставок), и хранит все решения, которые на нём сработали — и которые выглядели дёшево.

## Установка одной фразой

Откройте Claude Code (терминал, десктоп-приложение или IDE) и напишите:

> Установи сборку для рилсов по инструкции https://github.com/antuzinski/reels-pipeline/blob/main/INSTALL.md

Claude поставит всё сам (Windows или macOS), спросит только то, что требует вашего решения, и в конце проверит установку. Вручную — шаги в [INSTALL.md](INSTALL.md).

## Что внутри

| Папка | Что это |
|---|---|
| `skill/reels-pipeline/` | Скилл для Claude Code: весь процесс по шагам, грабли, [стилевые правила](skill/reels-pipeline/references/style.md), [инструменты](skill/reels-pipeline/references/tools.md) |
| `skill/reels-pipeline/scripts/` | Расшифровка через Whisper (локально), нарезка субтитров на смысловые фразы, склейки по расшифровке (паузы и дубли), громкость под стандарт −14 LUFS |
| `skill/reels-pipeline/components/` | Remotion-компоненты: «говорящая голова» со склейками, punch-in и наплывом, 12 вариантов замены фона (размытие, текст за головой, человек-стикер, параллакс…), субтитры с маркером, подсветкой ключевых слов и караоке, портрет-наклейка, мемный чувак с моноклем (5 эмоций), катаклизм на весь экран, иней, крэш-зум со словом, стоп-кадр «скрррч», «День 47-й», победитель с баблом, табло и др. |
| `tools/` | Библиотека звуков: страница-плеер, локальный помощник для сохранения, докачка целых записей |
| `sfx-library/` | Наш отбор звуков (`our-library.json`: «когда использовать») + сами избранные файлы. Полная библиотека (~1460 звуков CC0) скачивается при установке |
| `examples/frankenstein/` | Как был собран исходный ролик: сцены, тайминги, источники картинок |
| `Библиотека звуков.*`, `Открыть студию.*` | Ярлыки: `.bat` для Windows, `.command` для macOS |

## Как этим пользоваться

1. Снимите по [памятке](skill/reels-pipeline/references/shooting-and-cuts.md) (вертикально 4K, оговорился — пауза и фраза заново) и положите видео в `footage/`.
2. Скажите Claude: «сделай рилс из IMG_1234.MOV, начало с „…“, конец на „…“».
3. Он расшифрует речь, покажет текст с подозрительным оффтопом, предложит кадр 9:16, соберёт субтитры и графику — сначала стоп-кадрами, потом целиком.
4. Звуки он берёт только из вашей библиотеки и выбирает по вашим комментариям: откройте «Библиотека звуков», ставьте ★ и пишите, когда звук использовать.
