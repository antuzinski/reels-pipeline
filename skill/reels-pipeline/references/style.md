# Style decisions (user feedback, Frankenstein reel, Oct 2026)

## Captions
- White Montserrat 700 (slightly lighter than typical reels), soft dark shadow + thin dark stroke, **no background box**. ~76 px, centred, top ≈1060 so graphics fit below.
- Short meaningful phrases (~22 chars, ≤36 hard), each page ≥0.6–0.7 s. Never split: first name + surname («Джоном Полидори»), number + noun («1816 год»), «до сих пор», quotes («Вампир»); never end a line on a preposition/conjunction/adjective.
- Emphasis = same font, ×1.55, black text on yellow marker (#ffd60a), small pop. NOT a rubber stamp.

## Framing
- 9:16 crop centred on the rectangle the user marks; hands must not be cut. Start points to the exact decisecond the user gives.
- Leave background shadows alone if the crop already hides most of them.

## Graphics
- Small overlays: **bottom third only** (y ≥ 1280), never over the narrator's face, keep x ≤ 940 (Instagram buttons on the right).
- Portraits appear on **first mention**, as stickers: white border, soft shadow, light sepia, handwritten label (Caveat), springy entrance, gentle drift.
- Big beats go **full screen**: volcano → ash blackout → Pompeii with shake/zoom (liked a lot); crash zoom on a face + one punch word («Ставки!»); record-scratch freeze frame with a narrator plate («Это Байрон. Он ещё не знает, что проиграет»); rainy-window «День 47-й» meme; winner portrait with a **sarcastic speech bubble** and confetti; Orlok shadow full screen; real film clip full screen (mirrored + warm grade).
- Recurring character: primitive b/w **monocle guy** with line boil — the user loved him.
- Something new every 4–6 s, tied to the exact phrase: a shot-scale change, a word on screen, a picture of what is named. When nothing fits, a cut or a push is enough; never a decoration just to fill time.
- Content first: never pick a visual because a component exists or worked in an earlier reel. The Frankenstein components (MonocleGuy, Cataclysm, Frost, FreezeFrame, doodles…) are examples of kinds of solutions; reuse one only when the new line is literally about what it shows, at most once per reel. Before proposing a component, name the words of the line it shows; if it only decorates, drop it.
- Rejected as cheap: red stamp text, small crossed-out sun icon, small ash in the bottom third, crown on the winner, a plain white title page as a sticker (unreadable → draw a book cover instead), abstract walking figures, "elegant" mash-up meme for the new vampire.
- Atmosphere effects must stay subtle and creep in gradually (frost: thin edge only, light tint, few flakes) — the narrator must never get lost.

## Sound
- Few effects, only jokes/transitions, well under the voice. No whoosh after a sentence that doesn't cut to a new full-screen scene. Literal sound design (nut cracking, rain, volcano) is "дёшевка".

## Process
- Show stills per scene before animating; deliver full renders as numbered versions (v2, v3…); self-review the render with the `watch` skill before sending.
