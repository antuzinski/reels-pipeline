# Съёмка и монтаж «говорящей головы» для рилса

## Съёмка

**Ориентация.** Только для рилсов → снимать **вертикально, 4K 30 fps** (2160×3840): кроп не нужен, запас по резкости под зумы ~2×. Нужен ещё и горизонтальный ролик (YouTube) → снимать горизонтально 4K и кропать 9:16 из центра (запас ~1,1× при родном кропе 1215×2160; не центрировать лицо слишком близко к краю).

**Телефон.**
- Основная камера 1× (не широкий угол — искажает лицо), на уровне глаз, ~1,1–1,3 м от лица.
- Зафиксировать фокус и экспозицию (iPhone: долгое нажатие на лицо → «Фиксация экспозиции/фокуса»), иначе картинка «дышит» при жестах.
- Кадр: глаза примерно на 1/3 сверху, над головой немного воздуха, руки в кадре при жестах. Сверху/снизу кадра оставить запас — punch-in его съест.
- Видео 4K 30 fps, HDR лучше выключить (проще цвет, меньше сюрпризов при перекодировании). Если телефон пишет HEVC — ок, рабочая копия всё равно в H.264.

**Свет.** Основной источник выше уровня глаз и сбоку 25–35°, наклонён вниз; слабая подсветка с другой стороны. От стены ≥1–1,5 м — тени уходят вниз и смягчаются. Одна стойка: телефон на уровне глаз, панель на выносе 50–70 см и выше, маленькая лампа на клемпе с другой стороны.

**Звук.** Петличка (беспроводной микрофон) — лучше любого встроенного. Комната без эха (ковёр, шторы, мебель). Холодильник/вентилятор выключить. Проверить уровень: громкая фраза не должна «краснеть».

**Дубли — главное для монтажа.**
- Оговорились → **пауза 1–2 секунды** (молча, не двигаясь) → повторить **фразу целиком с начала предложения**. Пауза = место для склейки, повтор целиком = чистый дубль.
- Не говорить «стоп/ещё раз» — если вырвалось, всё равно сделать паузу; при нарезке это уйдёт.
- В начале и конце записи молчать 1–2 с, смотреть в камеру.
- Можно писать одним файлом или разбить на несколько видео по смысловым блокам.
- Сценарий/тезисы — заранее; спорные факты проверить (Claude может проверить).

## Монтаж (что делает Claude)

1. **Расшифровка** со словами и таймингами (`scripts/transcribe.mts`).
2. **Выбор дублей.** Если фраза повторена — оставить **последний чистый** дубль, слова неудачных удалить из `X.clean.json`. Показать пользователю текст с отмеченными удалениями до сборки.
3. **Нарезка.** `node scripts/make-cuts.mjs captions/X.clean.json captions/X.segments.json --gap 450 --pad 120 --min 500` — куски речи без длинных пауз и без удалённых дублей (дыры по времени становятся склейками). Для плотного темпа `--gap 300`; для спокойного `--gap 700`.
4. **Рабочая копия с запасом под зум.**
   - вертикальный 4K: `ffmpeg -i X.MOV -vf "scale=1350:2400:flags=lanczos" -c:v libx264 -crf 16 -preset medium -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart public/X_proxy.mp4` (запас 1,25×);
   - горизонтальный 4K: родной кроп без уменьшения `-vf "crop=1215:2160:<x>:0"` (запас 1,125×).
5. **Склейки и наплыв** — компонент `TalkingHead` (`segments`, `punchIn=1.1`, `pushIn=0.03`, `focusX/focusY` — точка лица в %): каждый второй кусок крупнее (punch-in — склейка читается как смена плана), внутри куска медленный наплыв +3 %. Сильнее 1,15 не делать — лицо режется. Склейку дополнительно можно закрыть графикой или тихим «вжухом».
6. **Ключевые слова** — `highlightWords={[...]}` у `TalkingHead`/`ReelCaptions`: слово жёлтым внутри обычной строки (совпадение по началу слова: «Франкенштейн» подсветит и «Франкенштейна»). 1–2 слова на фразу максимум, иначе подсветка теряет смысл. `karaoke` — подсветка звучащего слова (альтернативный стиль, не смешивать с `highlightWords` в одном ролике). Целая фраза-панчлайн — `emphasize` (крупно на маркере).
7. **Громкость.** После рендера: `node scripts/loudness.mjs out/X.mp4 out/X-final.mp4` → −14 LUFS, true peak ≤ −1,5 dBTP (стандарт Instagram/TikTok/YouTube). Видео копируется без перекодирования. Отдавать пользователю файл `-final`.
8. **Самопроверка** — `watch` по финальному файлу: склейки без рывков посреди слова, зум не режет лицо/руки, подсветка не на каждом слове.
